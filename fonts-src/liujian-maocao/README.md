# 柳建毛草（Liu Jian Mao Cao）品牌字体

- 来源：Google Fonts（github.com/google/fonts，ofl/liujianmaocao）
- 许可：SIL Open Font License 1.1（见同目录 OFL.txt），可自由随仓库与安装包再分发
- 用途：仅取「飞白」二字子集（scripts/subset-brand-font.mjs → public/fonts/brand/feibai-brand.woff2，~1.2KB），
  用于左上角品牌字（tabMethods），替代不可再分发的书法 JPG 品牌图
- 重新生成：npm run font:brand（需 devDependencies 的 subset-font）
